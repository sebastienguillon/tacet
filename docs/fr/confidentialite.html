Où il s’exécute

Tacet s’exécute sur les pages web que vous ouvrez en http ou https, dans la page elle-même et non dans les cadres qu’elle intègre, dès que la page commence à se charger. Il ne s’exécute pas sur les pages du navigateur, sur les boutiques d’extensions, ni sur les fichiers ouverts depuis votre ordinateur. Tout son code est dans le paquet installé ; il ne charge rien depuis internet.

Ce qu’il lit et pourquoi

  • La mise en page : quels éléments se superposent aux autres, leur taille et leur position, et les styles qui bloquent le défilement ou floutent le contenu. C’est ainsi que Tacet distingue un mur du reste de la page.
  • Le texte visible et les noms (identifiants, classes, libellés) de ces éléments, pour reconnaître le vocabulaire du consentement, des abonnements, des lettres d’information et des bloqueurs de publicité, en cinq langues.
  • Le bouton ou le lien sur lequel vous cliquez ou appuyez (son texte, son nom et son adresse), pour laisser en place ce que vous ouvrez vous-même, comme un formulaire de connexion ou les réglages de cookies du site.

Tout cela se passe dans la page, en mémoire, et est oublié quand vous la quittez. Tacet ne lit ni ce que vous saisissez dans les formulaires, ni vos cookies, ni vos mots de passe, ni votre historique.

Ce qu’il conserve

  • Dans le stockage des extensions du navigateur, sur cet appareil uniquement (sans synchronisation) : là où Tacet s’exécute (tous les sites, les sites choisis ou aucun), les sites où vous l’avez activé ou désactivé, le fait qu’il masque ou non les bandeaux de cookies qui ne bloquent pas la page, et l’activation ou non du journal de débogage.
  • La liste de ce que Tacet a changé sur une page reste dans la mémoire de cette page, pour que sa fenêtre puisse l’afficher. Elle disparaît quand vous quittez ou rechargez la page.
  • Quand le journal de débogage est activé, Tacet écrit aussi cette liste dans la page, comme attribut de son élément racine, et dans la console de la page, où les scripts de la page pourraient la lire. Le journal de débogage est désactivé par défaut.

Ce qu’il envoie

Rien. Tacet ne fait aucune requête réseau : ni statistiques, ni télémétrie, ni rapports de plantage. Les mises à jour passent par la boutique d’extensions de votre navigateur.

Autorisations

  • storage, pour conserver les réglages décrits plus haut.
  • L’accès à tous les sites. Tacet doit s’exécuter sur chaque page pour y trouver ses murs ; Chrome l’affiche comme « Lire et modifier toutes vos données sur tous les sites web », Firefox comme « Accéder à vos données pour tous les sites web ». Tacet s’en sert uniquement pour masquer les murs et rétablir la page comme décrit ici. Sur un site où il est désactivé, il lit seulement ses propres réglages et laisse la page intacte.
  • Sur Firefox, Tacet déclare ne collecter aucune donnée.

Vos choix

Depuis la fenêtre de Tacet, vous pouvez l’exécuter sur tous les sites, seulement sur les sites que vous choisissez, ou sur aucun, l’activer ou le désactiver pour un site, annuler ses changements sur la page en cours, ou l’empêcher de masquer les bandeaux de cookies qui ne bloquent pas la page. Supprimer l’extension efface ses réglages. Rien sur vous n’est conservé ailleurs.

Ce site

Ce site n’utilise aucune statistique et ne dépose aucun cookie. Il est hébergé sur GitHub Pages ; GitHub peut enregistrer l’adresse IP des visiteurs pour des raisons de sécurité, selon la déclaration de confidentialité de GitHub. La démonstration de la page d’accueil exécute le code de Tacet sur une page inventée ; son mur de consentement inventé n’enregistre rien.

Questions

Posez-les dans les tickets GitHub du projet. Les tickets sont publics : n’y mettez aucune information personnelle. La page d’aide répond aux questions courantes.

Tacet est un projet indépendant de Sébastien Guillon. Il n’est lié à aucun des sites ni des outils de consentement qu’il traite.
